**Task ID**: bug004

## Summary

Fixed the MASQUE HTTP/2 tunnel to be fully functional by implementing RFC 9297 capsule encoder/decoder and the h2 ↔ loopback QUIC bridge tasks. Previously, the `create_loopback_quic_pair` function was a placeholder that never bridged any data.

## Key Changes

1. `H2Tunnel` fields: `_conn_task` → `conn_task`, `_send_stream` → `send_stream`, `_recv_stream` → `recv_stream`
2. New `encode_datagram_capsule()` — RFC 9297 §5 capsule encoder returning `Bytes`
3. New `decode_datagram_capsule()` — RFC 9297 §5 capsule decoder
4. New `decode_h2_varint()` — QUIC-style varint decoder for h2 capsule data
5. `create_loopback_quic_pair()` — replaced placeholder with full bidirectional h2 ↔ QUIC bridge
6. Removed `#[allow(dead_code)]` from `encode_varint` and `varint_len` (now used by encoder)
